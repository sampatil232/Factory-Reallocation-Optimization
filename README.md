# Factory Reallocation & Shipping Optimization Recommendation System

## Project Overview
A machine learning based decision-support system for Nassau Candy Distributor.

## Features
- Shipping lead time prediction
- Factory reassignment recommendation
- Route clustering
- Scenario simulation
- Streamlit dashboard

## Technologies
Python
Pandas
Scikit-learn
Streamlit

## Run Project

Install dependencies:

pip install -r requirements.txt

Run dashboard:

streamlit run streamlit_app/app.py
